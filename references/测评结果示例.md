# 测评结果格式示例

本文件为测评结果的格式参考。默认使用长程任务模板；只有用户明确要求 Coding 模式时，才使用文末的 Coding 示例。

---

## 格式规则

1、顶部放评分汇总表格，方便一眼看全局
2、每个模型按顺序放：产物质量 → 执行过程 → 执行过程圈选评论 → 产出物反馈
3、“产物质量”“执行过程”“执行过程圈选评论”“产出物反馈”使用三级标题
4、“归因标签”使用四级标题，标签内容加粗
5、评分依据引用归因标签时，使用红色标签开头：`1、<strong style="color:#d93025">【标签】</strong>具体问题`
6、产物质量和执行过程的评分依据各至少写 4 条
7、执行过程圈选评论必须有，每个模型至少 3 处；没有足够缺点时用亮点补足
8、文件名:行号用正文，不加反引号；代码片段用代码块；说明用正文
9、所有列表用 `1、` `2、` 中文顿号序号，不使用 `1.`
10、评论用大白话，不写“架构优雅”“模块化良好”等空话
11、产出物反馈逐条使用截图文件名原话，不改写、不归纳，不保留 `.png`、`.jpg`、`.jpeg` 等图片后缀
12、执行过程里的效率只写相对排名，不写具体耗时和工具调用数值
13、产物质量、执行过程和执行过程圈选评论按用户本人准备提交平台的第一人称立场写，用自然大白话；可以直接描述模型行为，不要求每句话都加“我”
14、禁止写“用户认为”“人工验收认为”“自动化测试认为”“GPT 侧判断”等暴露第三人称代写或后台整理过程的表述
15、产出物反馈仍只搬截图文件名原话；提交简评、证据与限制、评分检查、数据统计和批次汇总不强制第一人称，不得把口吻调整扩大到用户未点名的章节

## cliff

### 评论（截图证据）

1、首页没问题
2、更换主题有 bug，点击另一个主题，选择主题弹窗会继续弹出一次
3、星火主题的排版不对，没有居中
4、点击分享有问题，预期是分享海报页面，然后可以点击保存到本地的

### 评分

总分 6/10：需求 3/5；代码 2/3；轨迹 1/2。封顶：否。

需求：
1、主题切换弹窗有 bug，点另一个主题后弹窗会再弹一次，体验很割裂
2、星火主题排版没居中，语录文字偏左
3、分享直接下载了，没有预览海报的步骤
4、首页、翻书动画、卡片翻转、洗牌袋都正常

代码：
1、有两个文件写了没被引用，死代码
2、用了小程序的标签没改成 HTML 标准标签
3、canvas.js 两个模板函数大量重复，800行

轨迹：
1、星火居中和分享预览这种基本验收没验过就交了

### 交付效率

效率分 7/10（耗时 12min，工具轮次 45，用户轮次 1）
整体还行，中间在主题切换那块试了两种方案

### 轨迹圈选

1、pwa/src/components/TemplateSelector.js:128-133 — 选主题后弹窗重复弹出

```js
container.querySelectorAll('.ts-item').forEach(item => {
    item.addEventListener('click', () => {
      const template = item.dataset.template;
      if (onChange) onChange(template);
      setTimeout(() => renderTemplateSelector(container, { ...options, currentTemplate: window.globalState.currentTemplate }), 50);
    });
  });
```

说明：选主题后 setTimeout 50ms 重新 render 整个面板，导致弹窗再弹一次

2、pwa/src/pages/result.js:438-469 — 分享直接下载没有预览

```js
canvas.toBlob(async (blob) => {
  if (!blob) { alert('生成图片失败'); return; }
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = `毛选语录_${Date.now()}.png`;
  document.body.appendChild(a);
  a.click();
```

说明：没有预览步骤，直接 toBlob 后触发下载。应该先展示海报让用户确认再保存

## gale

1、抽卡结果页语录内容都没有，基础功能都没有做好，无法使用，需要自己小修复才行
2、分享图片页没啥问题
3、点击更换主题，弹窗不会正常收起，需要二次点击，小的体验问题，影响不大

### 评分

总分 4/10：需求 2/5；代码 2/3；轨迹 0/2。封顶：是（核心需求未完成，≤6）。

需求：
1、抽卡结果页语录内容完全不显示，核心功能坏了
2、需要自己修复才能用，出厂就是坏的
3、分享图片页没问题

代码：
1、结构是四个里最好的，独立组件、fonts.ready、SW 文件全对得上
2、但跑起来核心功能不工作，有运行时数据传递 bug

轨迹：
1、语录为空打开就能看到，明显没做 UI 验证就交了，0 分

### 交付效率

效率分 4/10（耗时 22min，工具轮次 71，用户轮次 1）
工具轮次最多，数据传递那块删了重写了两遍
