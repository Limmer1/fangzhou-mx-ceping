# 测评结果格式示例

本文件是 Coding 与 Agent 共用的测评结果格式参考。两类任务都使用平台 1–10 分结构，证据定位方式按任务类型调整。

---

## 格式规则

1、顶部放评分汇总表格，方便一眼看全局
2、每个模型按顺序放置，依次为产物质量 → 执行过程 → 执行过程圈选评论 → 产出物反馈
3、“产物质量”“执行过程”“执行过程圈选评论”“产出物反馈”使用三级标题
4、“归因标签”使用四级标题，标签内容加粗
5、产物质量和执行过程的评分依据引用归因标签时，只写普通文本，格式为 `1、【标签】具体问题`；禁止使用颜色、HTML 或其他样式
6、产物质量和执行过程的评分依据各至少写 4 条
7、执行过程圈选评论必须有，每个模型至少 3 处；没有足够缺点时用亮点补足
8、Coding 圈选使用真实文件、行号和代码片段；Agent 圈选使用可复核的轨迹、章节、页面、页码、单元格、链接或产物位置
9、所有列表用 `1、` `2、` 中文顿号序号，不使用 `1.`
10、评论用大白话，不写“架构优雅”“模块化良好”等空话
11、产出物反馈逐条使用截图文件名原话，不改写、不归纳，不保留 `.png`、`.jpg`、`.jpeg` 等图片后缀
12、执行过程里的效率只写相对排名，不写具体耗时和工具调用数值
13、产物质量、执行过程和执行过程圈选评论按用户本人准备提交平台的第一人称立场写，用自然大白话；可以直接描述模型行为，不要求每句话都加“我”
14、禁止写“用户认为”“人工验收认为”“自动化测试认为”“GPT 侧判断”等暴露第三人称代写或后台整理过程的表述
15、产出物反馈仍只搬截图文件名原话；提交简评、证据与限制、评分检查、数据统计和批次汇总不强制第一人称，不得把口吻调整扩大到用户未点名的章节
16、评分表的模型行和逐模型章节按 `1、模型名` 这类文件夹序号排列，表格里只显示模型名，不按字母、得分或效率重排；排名字段和综合排名仍写真实名次
17、比较对象统一写“4个模型”“3个模型”或“这些模型”，不用“四家”“三家”“几家”
18、每个评价小点以 40–50 个汉字为目标，最多 50 个汉字；纯数据项、检查项和原始证据不强行凑字数
19、评价正文不使用中文冒号或英文冒号；文件路径行号、URL、代码、原始引用和平台字段保持原样
